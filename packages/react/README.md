# @memento/react

React UI for JSMemento: `MementoProvider`, a live sortable/filterable event table, chat and search components, `useMementoEvents` / `useMementoChat` hooks and a themeable `@memento/react/styles.css`.

Part of [JSMemento](https://github.com/digital-cube/jsmemento), a self-hosted, tenant-isolated
activity ledger. Docs: [REACT](https://github.com/digital-cube/jsmemento/blob/main/docs/REACT.md).

Requires Node 24+. MIT licensed.
