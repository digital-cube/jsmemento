# @memento/cli

The `memento` command line: setup wizard, tenants, API keys, templates, chats, lookups and `memento tail` (live stream). Reads `DATABASE_URL` / `REDIS_URL` like the server.

Part of [JSMemento](https://github.com/digital-cube/jsmemento), a self-hosted, tenant-isolated
activity ledger. Docs: [CLI](https://github.com/digital-cube/jsmemento/blob/main/docs/CLI.md).

Requires Node 24+. MIT licensed.
