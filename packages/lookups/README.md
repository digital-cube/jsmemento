# @memento/lookups

Controlled vocabularies for JSMemento: `lookups.yaml` compiler and registry, CSV translations with a validator, candidate recording for unknown values, and TypeScript/Zod codegen.

Part of [JSMemento](https://github.com/digital-cube/jsmemento), a self-hosted, tenant-isolated
activity ledger. Docs: [TEMPLATES](https://github.com/digital-cube/jsmemento/blob/main/docs/TEMPLATES.md).

Requires Node 24+. MIT licensed.
