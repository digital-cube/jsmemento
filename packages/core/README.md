# @memento/core

The JSMemento protocol: Zod schemas and inferred types for events, tenants, API keys, chats and the Filter DSL; `MementoClient` (typed HTTP client) and `MementoStream` (WebSocket client with reconnect).

Part of [JSMemento](https://github.com/digital-cube/jsmemento), a self-hosted, tenant-isolated
activity ledger. Docs: [API](https://github.com/digital-cube/jsmemento/blob/main/docs/API.md), [STREAMING](https://github.com/digital-cube/jsmemento/blob/main/docs/STREAMING.md).

Requires Node 24+. MIT licensed.
