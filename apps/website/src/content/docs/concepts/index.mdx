This section will explain the ideas memento is built on: an event tied to an instance
(`user/42`, `ticket/T-777`), the ledger that never rewrites what it recorded, the tenant every
key and event belongs to, the templates that turn an event into a sentence per language, the
live stream, and the UDC collections the sites read.

Until these pages are written, the
[philosophy note](https://github.com/digital-cube/jsmemento/blob/main/docs/PHILOSOPHY.md) in the
repository is the closest thing to them.
