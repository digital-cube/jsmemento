memento keeps a ledger of what happened in your applications. An event is tied to an instance
(`user/42`, `ticket/T-777`) and to the tenant whose key pushed it; it is never rewritten, turned
into a sentence in the reader's language, streamed as it is stored, and read back through
collections a UI can filter, sort and page. These pages explain each idea once; the
[Reference](/reference/) has every route and option.
