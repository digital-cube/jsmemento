This section will present the client programs in JavaScript, TypeScript, Python, PHP, Java,
Rust, Go and C++: each pushes a `USER_LOGIN`, reads the last ten events of its user and tails
the stream for ten seconds, with the key and the URL from the environment.

The programs exist already, in the repository's
[clients/](https://github.com/digital-cube/jsmemento/tree/main/clients) directory; their pages
here are not written yet.
