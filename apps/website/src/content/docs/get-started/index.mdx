memento is a server your applications push events to and read them back from. There are three
ways to have one: run it yourself, use the stage service with a key of your own, or put it inside
a Node application you already have. Each page ends with a `USER_LOGIN` pushed and read back as
`User igor logged in.` and `Korisnik igor se prijavio.`

## What you need

- **Docker** with Compose, for the first page. The stack brings its own database and Redis.
- **Node 24** for the embedded server and the JavaScript client (the client runs on Node 22 too);
  the other seven clients need their own toolchain, nothing else.
- **PostgreSQL 18** when you run memento outside Docker. Every table it creates is named
  `memento_*`, so it can share your application's database.
- **Redis**, optional. One process streams its own events in memory; with more than one, Redis
  carries every stored event to every process's `/ws` clients.

Every command on these pages was run as it is written here, against a fresh clone and the stage
service; what a step prints is what it printed then, with ids shortened where they would only
be noise.
