This section will take you from nothing to your first event: run memento with Docker, create a
tenant and an API key (or get one from the <a href={SERVICE_URL}>service site</a>), push a
`USER_LOGIN` and read it back as `User igor logged in.`

The pages are being written. Until they are here, the quick start lives in the repository's
[README](https://github.com/digital-cube/jsmemento#run-it-with-docker) and
[docs/DEPLOYMENT.md](https://github.com/digital-cube/jsmemento/blob/main/docs/DEPLOYMENT.md).
